# Chigwell

Chigwell is served by the Central line (Hainault loop), in the Epping Forest district of Essex, just beyond the northern edge of Greater London.

## Summary

| London Underground station | Finnish translation |
| -------------------------- | ------------------- |
| Chigwell                   | Kiikankaivo         |

## Background

Local tradition explains Chigwell as "king's well," after a supposed lost spring, but that is folk etymology. [The accepted scholarly derivation is "Cicca's well"](https://en.wikipedia.org/wiki/Chigwell) — the Old English personal name _Cicca_ plus _wella_ (well) — supported by medieval spellings such as _Cinghe uuella_ and _Chikewelle_.

## Direct translations

| English               | Finnish  |
| --------------------- | -------- |
| well (_wella_)        | kaivo    |
| Cicca (personal name) | — (name) |
| king (folk reading)   | kuningas |

The _wella_ is straightforward: _kaivo_, a well. The first element is not "king" (_kuningas_) but the personal name _Cicca_, which carries no meaning to translate. As at [Bermondsey](bermondsey.md), the honest route for an opaque name is a real Finnish echo: [_Kiikka_](https://fi.wikipedia.org/wiki/Kiikka), a genuine old Finnish place (a former municipality now part of Sastamala), stands in for Cicca. The result is _Kiikankaivo_, "Kiikka's well."

## Conclusion

Dropping the folk "king," Chigwell is simply somebody's well. Chigwell station in Finnish shall be called _Kiikankaivo_.
