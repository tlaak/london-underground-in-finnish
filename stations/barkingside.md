# Barkingside

Barkingside is served by the Central line (Hainault loop), in the London Borough of Redbridge in East London.

## Summary

| London Underground station | Finnish translation |
| -------------------------- | ------------------- |
| Barkingside                | Parkinpuoli         |

## Background

[Barkingside is thought to be named for its position on the Barking side of Hainault Forest](https://en.wikipedia.org/wiki/Barkingside) — that is, the side nearer the town of Barking. The distinctive element to translate is really "-side."

## Direct translations

| English | Finnish |
| ------- | ------- |
| Barking | Parkin  |
| side    | puoli   |

"Side" is _puoli_. "Barking" itself derives from an Old English group-name (the people of a man such as _Berica_) with no Finnish meaning to carry over, so it is Finnicised by sound to _Parkin_ — a close echo of "Barking." The result is _Parkinpuoli_, "the Barking side."

Note that the parent station Barking is not yet translated; when it is, it should take the same root (_Parkki_ / _Parkin_) so the pair stays consistent.

## Conclusion

Barkingside station in Finnish shall be called _Parkinpuoli_.
