# Bethnal Green

Bethnal Green is served by the Central line, in the London Borough of Tower Hamlets in the East End.

## Summary

| London Underground station | Finnish translation |
| -------------------------- | ------------------- |
| Bethnal Green              | Onnikulmanniitty    |

## Background

The favoured derivation traces Bethnal Green to an Anglo-Saxon [_Blithehale_ / _Blythenhale_](https://en.wikipedia.org/wiki/Bethnal_Green), from _healh_ ("an angle, nook or corner") with a first element _blithe_ ("happy, pleasant") or the personal name _Blitha_ — so "the pleasant corner." (An older suggestion derived it from a "Bathon Hall" family, but the _-healh_ reading is now preferred.) "Green" was the common land on which the settlement grew.

## Direct translations

| English                | Finnish |
| ---------------------- | ------- |
| _blithe_ (happy)       | onni    |
| _healh_ (corner, nook) | kulma   |
| green (common land)    | niitty  |

Read as "blithe corner," the first two elements give _Onnikulma_, "happy corner." For "Green," the sense is a village green or common — grassy open land — so _niitty_ (meadow), not _korpi_ (deep backwoods, which an earlier draft used and which meant the opposite kind of ground). Together: _Onnikulmanniitty_.

## Conclusion

Bethnal Green station in Finnish shall be called _Onnikulmanniitty_, "the green of the happy corner."
